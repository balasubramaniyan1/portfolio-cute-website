# Personal Portfolio Website

A simple personal portfolio website created using **HTML and CSS**. The website is designed with a clean and minimal layout to introduce myself and provide a way for visitors to get in touch with me.

## 📄 Pages

* **Home** – Introduces me and provides an overview of my profile and skills.
* **Contact** – Allows visitors to find my contact information and get in touch with me.

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 🎯 Purpose

This project was created to practice my front-end development fundamentals and build a simple personal portfolio website using basic HTML and CSS.
